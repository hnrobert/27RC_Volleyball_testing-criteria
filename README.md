## 1. 概述

### 1.1 目的

本方案规定长基线双目系统标定测试的测试项目、测试方法、量化指标、合格判据与评分规则，
用于给出可审计的单项得分与整机等级结论（A/B/C/F）。

### 1.3 深度模型与误差传播

双目深度由视差计算：

$$
Z = \frac{fB}{d}
$$

对视差误差 δd 做一阶近似：

$$
\delta Z \approx \frac{Z^2}{fB}\,\delta d
\quad\Longleftrightarrow\quad
\frac{\delta Z}{Z} = \frac{Z\,\delta d}{fB}
$$

即深度相对误差与距离 Z 成正比、与基线 B 成反比。**本文所有距离相关阈值均按上式换算**
（约定 δd₀ = 0.5 px，见附录 A）；像素类阈值（重投影 / 极线 / 视差）为绝对值。

### 1.4 测试分类

- **A 类（核心标定质量，T01–T10）**：必测项目，不允许 N/A。用于判定"标定是否合格"。
- **B 类（环境与系统可靠性，T11–T15）**：默认全测；确不具备条件时可记 N/A（见 3.5 节）。

## 2. 通用测试条件

除单项测试另有规定外，均执行以下条件：

1. **标准环境**：温度 23 ± 2 °C，相对湿度 40%–70%，无强气流、无明显振动与电磁干扰。
2. **标定物**：棋盘格标定板（推荐内角点数 ≥ 10 × 7，格边长制造公差 ≤ ±0.1%，
   平面度 ≤ 0.5 mm / 全板）或 AprilTag 阵列板。
3. **Ground truth 器具**：激光测距仪 / 全站仪 / 激光跟踪仪，测量不确定度 ≤ 被测指标
   合格阈值的 1/3，且在计量有效期内。
4. **预热**：测试前整机连续通电 ≥ 30 min，达到热稳定。
5. **随机化**：标定板摆放次序随机化，避免顺序性系统偏差。
6. **数据留存**：每项测试保存原始图像、标定参数文件、中间结果与日志；异常情况必须备注。
7. **统一记录**：每项测试记录测试日期、环境参数、操作员、原始数据路径。

## 3. 评分体系

### 3.1 单项评分规则

每个定量指标按阈值分四档打分：

| 档位 | 得分 | 含义 |
| --- | ---: | --- |
| 优 | 100 | 显著优于要求 |
| 良 | 80 | 满足要求且有余量 |
| 合格 | 60 | 勉强满足要求 |
| 不合格 | 0 | 不满足要求 |

一项测试含多个指标时，**取所有指标中的最低档作为该项得分**（木桶原则），
避免单项指标间相互掩盖。

| T03 | 标定重复性 | A | 8 |
| T04 | 标定板空间覆盖 | A | 6 |
| T05 | 不同距离深度误差 | A | 8 |
| T06 | 深度精度 | A | 10 |
| T07 | 三轴（X/Y/Z）定位精度 | A | 6 |

| T09 | 视差精度 | A | 4 |
| T10 | 目标姿态适应性 | A | 4 |

### 3.3 否决项

出现下列任一情况，整体直接判定为 F（不合格），与总分无关：

| 编号 | 否决条件 |
| --- | --- |
| V1 | T01 单目重投影 RMS 或 T02 双目重投影 RMS 落在"不合格"档 |
| V2 | T08 极线误差 RMS 超过合格档（> 0.50 px） |
| V3 | T12 机械稳定性触发"标定失效"判据（ΔB/B 或 ΔR 任一超合格档） |
| V4 | 测试过程中出现程序崩溃、无深度输出等致命功能故障 |

### 3.4 总分与等级

$$
S = \frac{\sum_i w_i \, s_i}{\sum_i w_i} \times 100
$$

其中 wᵢ 为执行项权重，sᵢ 为该项得分百分值。

| 等级 | 判定条件 | 结论 |
| --- | --- | --- |
| A（优秀） | S ≥ 90，无否决项，A 类无缺测 | 标定质量优秀，可直接交付 |
| B（良好） | 80 ≤ S < 90，无否决项 | 标定质量良好，可交付 |
| C（合格） | 70 ≤ S < 80，无否决项，A 类无 0 分项 | 有条件交付，需列出改进项 |
| F（不合格） | S < 70，或触发任一否决项 | 标定不合格，须整改后重新测试 |

### 3.5 N/A 规则

B 类测试确不具备执行条件（如无温箱、无振动台）时记 N/A，从权重中剔除后按剩余项
归一化计算总分，并在报告中注明原因。**A 类（T01–T10）不允许 N/A。**

### 3.6 阈值基准与换算

本文示例阈值基于参考配置：**B = 1.000 m，f = 2200 px，工作距离 5–100 m**。

- 像素类阈值（重投影 / 极线 / 视差误差）：绝对值，一般不需换算。
- 距离类阈值（深度误差）：按理论误差 δZ_th(Z) = Z² · δd₀ / (fB)（δd₀ = 0.5 px）换算，
  分档系数为 优 1.5× / 良 2.5× / 合格 4.0×，详见附录 A。

实际设备的 B、f 与参考配置不同时，必须按附录 A 重算距离类阈值表后再执行判分。

## 5. 详细测试规程

### T01 单目标定质量测试（权重 6）

**测试目的**：验证左、右相机内参（$f_x$, $f_y$, $c_x$, $c_y$）与畸变参数的可靠性，
排除内参误差对后续所有测试的污染。

**环境与器材**：标准环境（§2）；棋盘格标定板。

**输入与样本量**：每相机 ≥ 20 个板位；板位须覆盖图像各区域（含四角）、不同距离与
不同倾角（相对光轴 ≤ 45°）。

**测试步骤**：

1. 完成预热（§2 第 4 条）后固定相机；
2. 依次摆放 ≥ 20 个板位，每位采集 ≥ 5 帧清晰图像（无运动模糊、无过曝、无失焦）；
3. 分别对左、右相机执行内参与畸变标定；
4. 计算每板位、每角点的重投影误差向量；
5. 统计 RMS / Mean / Max，以及 X、Y 方向分量均值；
6. 绘制误差向量图、误差热力图、分板位误差分布图。

**指标与评分**（左、右相机分别判档，取较差相机档位）：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| RMS 重投影误差 | ≤ 0.20 px | ≤ 0.35 px | ≤ 0.50 px | > 0.50 px |
| 平均重投影误差 | ≤ 0.15 px | ≤ 0.30 px | ≤ 0.40 px | > 0.40 px |
| 最大重投影误差 | ≤ 0.80 px | ≤ 1.50 px | ≤ 2.00 px | > 2.00 px |

**输出物**：内参表（f_x, f_y, c_x, c_y, k₁–k₅, p₁, p₂）、误差统计表、误差向量图、
误差热力图、左右相机 RMS 差值记录。

### T02 双目外参标定质量测试（权重 8）

**测试目的**：验证左右相机相对位姿 R_LR、T_LR 与基线 B = ‖T‖ 的标定准确性。

**环境与器材**：标准环境（§2）；高精度基线量具（激光跟踪仪 / 全站仪 / 数显量具），
其测量不确定度 ≤ 基线偏差合格阈值的 1/3。

**输入与样本量**：≥ 20 组左右同步板位（可与 T01 复用数据，但须含不同深度）。

**测试步骤**：

1. 以 T01 结果为初值，执行双目联合标定，得到 R_LR、T_LR；
2. 计算基线 B = ‖T‖ 与平移分量 T_x、T_y、T_z；
3. 将 R_LR 转换为 Roll / Pitch / Yaw 欧拉角；
4. 用量具实测基线基准 B_ref，计算 |ΔB| / B_ref；
5. 统计双目重投影误差 RMS（左右角点合并）。

**指标与评分**：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| 双目重投影 RMS | ≤ 0.25 px | ≤ 0.40 px | ≤ 0.60 px | > 0.60 px |
| 基线偏差 \|ΔB\|/B_ref | ≤ 0.05% | ≤ 0.10% | ≤ 0.20% | > 0.20% |

**输出物**：R（3×3 矩阵与欧拉角）、T、B、双目 RMS 统计表、基线对比记录表。

### T03 标定重复性测试（权重 8）

**测试目的**：在硬件完全不动的前提下，量化标定流程本身的参数散布，
证明标定流程可靠、可复现。

**输入与样本量**：N = 10 次完全独立的标定（每次重新摆放板位、重新采集、重新标定，
流程与人员操作一致，硬件不动）。

**测试步骤**：

1. 重复执行 10 次"摆板 → 采集 → 标定 → 存档"完整流程；
2. 对每个参数（f_x, f_y, c_x, c_y, 畸变、B、欧拉角）计算均值与标准差；
3. 按下表判档，输出参数-次数曲线。

**指标与评分**（取全部指标最低档）：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| σ(B)/B | ≤ 0.02% | ≤ 0.05% | ≤ 0.10% | > 0.10% |
| σ(f_x)/f_x 且 σ(f_y)/f_y | ≤ 0.02% | ≤ 0.05% | ≤ 0.10% | > 0.10% |
| σ(c_x) 与 σ(c_y) | ≤ 0.5 px | ≤ 1.0 px | ≤ 2.0 px | > 2.0 px |
| σ(任一欧拉角) | ≤ 0.01° | ≤ 0.02° | ≤ 0.05° | > 0.05° |

**输出物**：参数-次数曲线（10 点）、σ 汇总表（附录 D 模板）。

### T04 标定板空间覆盖测试（权重 6）

**测试目的**：检查镜头边缘区域（含四角）的畸变模型与极线质量，
避免"仅图像中心有效"的标定。

**输入与样本量**：将视场划分为 3 × 3 共 9 个分区，每分区 ≥ 3 个板位；
距离覆盖近 / 中 / 远。

```text
┌──────────────────────┐
│   ①      ②      ③   │
│   ④      ⑤      ⑥   │
│   ⑦      ⑧      ⑨   │
└──────────────────────┘
```

**测试步骤**：

1. 按分区依次摆放标定板并采集；
2. 用统一标定结果计算各分区的重投影误差与极线误差；
3. 计算边缘分区与中心分区的 RMS 之比；
4. 输出 9 分区误差矩阵热力图。

**指标与评分**：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| 任一分区重投影 RMS | ≤ 0.30 px | ≤ 0.45 px | ≤ 0.60 px | > 0.60 px |
| 边缘区 / 中心区 RMS 比 | ≤ 1.3 | ≤ 1.6 | ≤ 2.0 | > 2.0 |
| 任一分区极线 RMS | ≤ 0.30 px | ≤ 0.40 px | ≤ 0.50 px | > 0.50 px |

**输出物**：9 分区重投影 / 极线误差矩阵热力图、分区统计表。

### T05 不同距离深度误差测试（权重 8）

**测试目的**：覆盖实际工作距离范围，测量深度误差随距离的变化规律，
并与理论模型 δZ ∝ Z² 对比验证。

**输入与样本量**：按工作范围取 ≥ 6 个距离点（参考：5 / 10 / 20 / 30 / 50 / 70 / 100 m），
必须包含最近距离、最远距离与常用工作距离；每距离 ≥ 30 个有效样本。

**测试步骤**：

1. 以激光测距仪测量标定物距离作为 Z_GT；
2. 系统输出 Z_stereo，计算相对误差 Er = |Z_stereo − Z_GT| / Z_GT；
3. 每距离统计 Er 的 RMS 并按阈值表判档；
4. 绘制 Depth Error ~ Distance 曲线（双对数坐标，叠加理论线）。

**指标与评分**（阈值 = 分档系数 × δZ_th(Z)，表中为参考配置示例；
Er 统计口径为每距离 RMS）：

| 距离 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| ---: | ---: | ---: | ---: | ---: |
| 5 m | ≤ 0.17% | ≤ 0.28% | ≤ 0.45% | > 0.45% |
| 10 m | ≤ 0.34% | ≤ 0.57% | ≤ 0.91% | > 0.91% |
| 20 m | ≤ 0.68% | ≤ 1.14% | ≤ 1.82% | > 1.82% |
| 30 m | ≤ 1.02% | ≤ 1.70% | ≤ 2.73% | > 2.73% |
| 50 m | ≤ 1.70% | ≤ 2.84% | ≤ 4.55% | > 4.55% |
| 70 m | ≤ 2.39% | ≤ 3.98% | ≤ 6.36% | > 6.36% |
| 100 m | ≤ 3.41% | ≤ 5.68% | ≤ 9.09% | > 9.09% |

T05 得分 = 所有距离中的最低档；任一距离不合格则 T05 = 0。

**理论一致性分析**（输出物，不计分）：对 Er(Z) 做双对数线性拟合，斜率 k 应接近 2；
k 明显偏离（k < 1.5 或 k > 2.5）时提示存在与距离无关的系统偏差或匹配退化，须在报告中分析。

**输出物**：误差-距离曲线（含理论线）、分距离误差表（附录 C 模板）、拟合斜率与决定系数。

### T06 深度精度测试（权重 10）

**测试目的**：在代表性距离上系统评估深度精度，给出 MAE / RMSE / 最大误差 / 3σ。

**输入与样本量**：≥ 3 个代表性距离（近 / 中 / 远），每距离 ≥ 30 个有效样本；
目标为标定板 / AprilTag 已知特征点。

**归一化指标定义**：为跨距离汇总，定义归一化误差

$$
\varepsilon = \frac{E_r}{\delta Z_{th}(Z)}, \qquad \delta Z_{th}(Z) = \frac{Z^2\,\delta d_0}{fB}
$$

对全部样本的 ε 序列统计 RMSE、最大值与 3σ。

**指标与评分**：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| RMSE(ε) | ≤ 1.5 | ≤ 2.5 | ≤ 4.0 | > 4.0 |
| Max(ε) | ≤ 2.0 | ≤ 3.5 | ≤ 6.0 | > 6.0 |
| 3σ(ε) | ≤ 2.5 | ≤ 4.0 | ≤ 6.0 | > 6.0 |

**输出物**：分距离 MAE / RMSE / Max / 3σ 汇总表（绝对值 + 相对值）、误差直方图、
误差-距离散点图。

### T07 三轴（X/Y/Z）定位精度测试（权重 6）

**测试目的**：检验完整 3D 输出 (X, Y, Z)，发现"深度很准但横向存在系统偏差"的问题。

**输入与样本量**：≥ 3 个距离 × ≥ 5 个已知横向偏移位置（覆盖视场不同区域），
≥ 30 个有效样本；横向 GT 由全站仪 / 精密导轨提供。

**测试步骤**：

1. 依次放置标定物于已知 (X_GT, Y_GT, Z_GT) 位置；
2. 系统输出 (X, Y, Z)，计算三轴误差序列；
3. 分轴统计 MAE / RMSE / Max 与均值（系统偏差 bias）。

**指标与评分**（Z 轴沿用 T06 判据；X/Y 轴为横向）：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| X 轴 RMSE | ≤ 0.05%·Z | ≤ 0.10%·Z | ≤ 0.20%·Z | > 0.20%·Z |
| Y 轴 RMSE | ≤ 0.05%·Z | ≤ 0.10%·Z | ≤ 0.20%·Z | > 0.20%·Z |
| Z 轴 RMSE | 同 T06 合格档 | | | |
| 系统偏差比 \|bias\|/RMSE（X、Y） | ≤ 0.3 | ≤ 0.5 | ≤ 0.8 | > 0.8 |

系统偏差比 > 0.5 时须在报告中分析横向系统偏差来源（外参平移、光轴不平行等）。

**输出物**：三轴误差汇总表（MAE / RMSE / Max）、bias 分析表、误差空间分布图。

### T08 极线校正质量测试（权重 10）

**测试目的**：验证双目校正后左右对应点共极线的程度——双目标定质量最直接、
最灵敏的指标。

**输入与样本量**：静态场景 ≥ 10 帧稠密特征匹配（或棋盘格角点），
共 ≥ 1000 个匹配点对，覆盖全视场与代表性距离。

**测试步骤**：

1. 对左右图像做立体校正（rectification）；
2. 提取并匹配特征点对（或检测角点对应）；
3. 计算每对点的垂直坐标差 e_y = |y_L − y_R|；
4. 统计 Mean / RMS / P95 / Max，并绘制 e_y 随图像坐标的分布。

**指标与评分**：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| Mean(e_y) | ≤ 0.15 px | ≤ 0.25 px | ≤ 0.40 px | > 0.40 px |
| RMS(e_y) | ≤ 0.20 px | ≤ 0.30 px | ≤ 0.50 px | > 0.50 px |
| P95(e_y) | ≤ 0.40 px | ≤ 0.60 px | ≤ 1.00 px | > 1.00 px |
| Max(e_y) | ≤ 1.0 px | ≤ 1.5 px | ≤ 2.0 px | > 2.0 px |

RMS(e_y) > 0.50 px 同时触发否决项 V2。

**输出物**：e_y 统计表、e_y 直方图、e_y 空间分布图（随 x、y 变化）。

### T09 视差精度测试（权重 4）

**测试目的**：将标定误差与匹配误差分离，验证实测视差与理论视差的一致性。

**输入与样本量**：在 T05 各距离上对标定物已知特征点，每距离 ≥ 100 个点。

**测试步骤**：

1. 由 GT 计算理论视差 d_theo = f·B / Z_GT；
2. 测量对应点实测视差 d_meas，计算 Δd = d_meas − d_theo；
3. 统计 Mean、Max 与 bias（Δd 均值）。

**指标与评分**：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| 平均 \|Δd\| | ≤ 0.10 px | ≤ 0.20 px | ≤ 0.30 px | > 0.30 px |
| 最大 \|Δd\| | ≤ 0.30 px | ≤ 0.50 px | ≤ 0.80 px | > 0.80 px |
| 系统偏差 \|bias_d\| | ≤ 0.05 px | ≤ 0.10 px | ≤ 0.20 px | > 0.20 px |

bias_d 显著非零提示标定参数（f、B 或 Z 方向平移）存在系统偏差，须溯源。

**输出物**：理论 vs 实测视差对比表（分距离）、Δd 分布直方图。

### T10 目标姿态适应性测试（权重 4）

**测试目的**：检验目标板倾斜（大入射角）时标定模型与特征检测的有效性。

**输入与样本量**：yaw ∈ {−20°, −10°, 0°, +10°, +20°} × pitch ∈ {−15°, 0°, +15°}，
固定代表性距离，每姿态 ≥ 20 个样本。

**测试步骤**：

1. 按姿态矩阵摆放标定板（姿态由云台 / 量角器保证，误差 ≤ 1°）；
2. 统计各姿态下的重投影误差、极线误差与深度 Er；
3. 计算恶化系数 κ = 指标(该姿态) / 指标(正对 0°, 0°)。

**指标与评分**：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| κ(深度 Er)（全姿态最大） | ≤ 1.2 | ≤ 1.5 | ≤ 2.0 | > 2.0 |
| κ(极线 RMS)（全姿态最大） | ≤ 1.2 | ≤ 1.5 | ≤ 2.0 | > 2.0 |
| 任一姿态重投影 RMS | ≤ 0.35 px | ≤ 0.45 px | ≤ 0.60 px | > 0.60 px |

任一姿态下深度 Er 仍须满足 T05 对应距离的合格档，否则直接判 0 分。

**输出物**：误差-yaw / 误差-pitch 曲线、姿态-指标矩阵表。

### T11 光照鲁棒性测试（权重 6，B 类）

**测试目的**：检验不同光照条件下的特征检测与深度输出稳定性。

**工况设置**：正常室内光（基准）、低照度（< 50 lux）、强光 / 直射、背光、局部阴影；
室外设备加测晴天、阴天、清晨 / 傍晚、强太阳光。每工况固定距离与目标，≥ 30 帧。

**测试步骤**：

1. 记录基准工况下的检出率、深度有效率与深度 Er；
2. 依次切换工况并重复测量；
3. 计算各工况相对基准的恶化系数。

**指标与评分**（各工况分别判档，取最差工况档位）：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |
| 标定特征检出率 | ≥ 99% | ≥ 97% | ≥ 95% | < 95% |
| 深度有效率 | ≥ 98% | ≥ 95% | ≥ 90% | < 90% |
| 深度 Er 恶化系数 | ≤ 1.2 | ≤ 1.5 | ≤ 2.0 | > 2.0 |

**输出物**：工况-指标汇总表、各工况代表性图像与深度图。

### T12 机械稳定性测试（权重 10，B 类）

**测试目的**：回答"设备经过运输 / 振动 / 重装之后，原标定参数还能不能继续用"。

**工况设置**（每工况结束后复测外参与代表性距离深度）：

1. 初始（基准）；
2. 振动台按运输规格振动（或等效路面运输模拟）；
3. 整机搬运 / 移动；
4. 相机拆装 1 次（重新安装至原位）；
5. 开关机 3 次。

**指标与评分**（相对初始标定，各工况分别判档取最差）：

| 指标 | 优（100） | 良（80） | 合格（60） | 不合格（0） |
| --- | ---: | ---: | ---: | ---: |

| ΔR（任一欧拉角） | ≤ 0.01° | ≤ 0.02° | ≤ 0.05° | > 0.05° |
| 复测深度 Er 恶化系数 | ≤ 1.1 | ≤ 1.2 | ≤ 1.5 | > 1.5 |

任一工况 ΔB/B 或 ΔR 超合格档即判定**标定失效**（否决项 V3），须重新标定并复测
T01–T10。

**输出物**：工况-ΔR / ΔT / ΔB / ΔEr 汇总表、标定有效性结论（是否需要现场重标定流程）。

## 7. 附录

### 附录 A 理论误差换算

约定视差误差基准 δd₀ = 0.5 px，理论深度相对误差：

$$
\frac{\delta Z_{th}(Z)}{Z} = \frac{Z\,\delta d_0}{fB}
$$

分档系数：优 ≤ 1.5×δZ_th，良 ≤ 2.5×δZ_th，合格 ≤ 4.0×δZ_th。

参考配置（B = 1.000 m，f = 2200 px）换算表：

| 距离 Z | δZ_th/Z（理论线） | 优（1.5×） | 良（2.5×） | 合格（4.0×） |
| ---: | ---: | ---: | ---: | ---: |
| 5 m | 0.11% | 0.17% | 0.28% | 0.45% |
| 10 m | 0.23% | 0.34% | 0.57% | 0.91% |
| 20 m | 0.45% | 0.68% | 1.14% | 1.82% |
| 30 m | 0.68% | 1.02% | 1.70% | 2.73% |
| 50 m | 1.14% | 1.70% | 2.84% | 4.55% |
| 70 m | 1.59% | 2.39% | 3.98% | 6.36% |
| 100 m | 2.27% | 3.41% | 5.68% | 9.09% |

**换算规则**：实际设备阈值(Z) = 分档系数 × Z × δd₀ / (f·B)。修改 B 或 f 后必须重算本表
与 T05 阈值表，并在报告中记录所用 f、B 数值。

**理论-实测一致性检验**：将实测 Er(Z) 与理论线同绘于双对数坐标；拟合斜率 k ≈ 2 为一致。
k 显著偏小说明误差由与距离无关的因素主导（如标定 bias），显著偏大说明匹配质量随距离退化。
